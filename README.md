# Agent-Based Simulation of Panic-Driven Crowd Evacuation

Agent-based simulation of evacuation dynamics under reduced visibility, built on the Mesa framework and extended with leader–follower interactions, dynamic fire propagation, and smoke-driven visibility loss.

---

## Features

- **Leader–follower modeling** with dynamic herding and panic behaviour  
- **Environmental hazards**: fire, smoke diffusion, and visibility decay  
- **Flexible configuration** of exits, crowd size, and agent parameters  
- **Interactive visualization** via [Solara](https://solara.dev)  
- **Data collection** for evacuation time, injuries, and behavioural metrics  

---

- **Python** ≥ 3.12.10  
- Dependencies listed in `requirements.txt`

## Installation

1. **Clone the repository**

   ```bash
   git clone <repository-url>
   cd dmas_project
   ```

2.	**Create a virtual environment (recommended)**

   ```bash
   python -m venv .venv
   source .venv/bin/activate      # Linux / macOS
   .venv\Scripts\activate         # Windows
   ```

3.	**Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

## Notebooks

### `src/notebooks/experiments.ipynb`

This Jupyter Notebook is the primary tool for running, managing, and analyzing simulation experiments. It provides a structured framework for defining experimental conditions, executing simulation runs, and saving the results in a consistent format.

The notebook is divided into two main parts:

-   **Baseline Experiment:** Replicates the classic "faster-is-slower" effect by varying agent desired speed (`v0`). Includes functions to plot evacuation success and injury rates against speed.
-   **Extended Experiment:** Implements the full 2 × 3 × 5 factorial design, testing the effects of fire, exit configurations, and leadership proportion. It also includes functionality for visualizing agent position heatmaps for specific conditions.

### `src/notebooks/simulation_results.ipynb`

This notebook is dedicated to analysis and visualization of the data generated by `experiments.ipynb`. It contains functions to load, aggregate, and plot results from the extensive factorial experiments.

Key features include:
-   **Data Aggregation:** A function (`load_combined_model_df`) that combines data from multiple simulation runs into a single, analysis-ready DataFrame.
-   **Generic Plotting:** A flexible plotting function (`plot_by_parameter`) that generates time-series plots of key metrics (e.g., remaining agents, average speed, injuries), averaged across all replicate runs for a given condition.
